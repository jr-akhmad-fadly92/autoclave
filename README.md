# autoclave

## Ringkasan
Sistem kontrol otomatis untuk mesin Autoclave berkapasitas 18 liter, digunakan
untuk sterilisasi alat medis di lingkungan CSSD (Central Sterile Supply
Department) rumah sakit/klinik. Sistem berbasis microcontroller ini mengatur
seluruh siklus sterilisasi secara otomatis — mulai dari pengecekan kondisi
air, pemanasan, vacuum, hingga proses pengeringan — tanpa perlu intervensi
manual dari operator di tengah proses.

## Peran Saya
Controls engineer — merancang logika kontrol, membangun panel kontrol
(wiring & perakitan), serta melakukan instalasi dan pengujian alat di lokasi
mitra.

## Tech Stack
- **Kontrol:** Microcontroller 
- **Sensor:** Sensor level air (bersih & kotor), sensor suhu, sensor tekanan
- **Aktuator:** Elemen pemanas, pompa vacuum, katup uap
